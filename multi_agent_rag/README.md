# Multi-Agent News Analysis System

Система мультиагентного анализа новостей для оценки реакции целевой аудитории на финансовые события. Использует RAG, векторный поиск и YandexGPT.

## Возможности

*   **4 агента-эксперта:** Макроэкономика, Банки, Валюта, Недвижимость.
*   **RAG-поиск:** Семантический поиск новостей в базе (Qdrant).
*   **Координация:** Агенты консультируются друг с другом для комплексного анализа.
*   **Отчетность:** Генерация текстовых и JSON-отчетов с триггерами и барьерами.

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install aiohttp sentence-transformers qdrant-client huggingface_hub
```

### 2. Настройка токенов
Откройте `config.py` и вставьте ваши данные Yandex Cloud:
```python
YANDEX_GPT_CONFIG = {
    "folder_id": "ваш_folder_id",
    "iam_token": "ваш_iam_token",
    # ...
}
```

### 3. Загрузка модели
```bash
python download_model.py
```

### 4. Запуск
```bash
python main.py
```
Введите целевую аудиторию и вопрос. Результат сохранится в папку `outputs/`.

## Структура проекта

| Файл | Описание |
|------|----------|
| `main.py` | Точка входа, запуск цикла обработки |
| `orchestrator.py` | Координация агентов и планирование консультаций |
| `agents.py` | Логика агентов и клиент YandexGPT |
| `config.py` | Настройки, промпты и категории |
| `rag_system.py` | Система поиска по базе знаний |
| `download_model.py` | Утилита загрузки embedding-модели |

## Результат

В папке `outputs/` создаются два файла:
*   `result_*.txt` — читаемый отчет с рассуждениями агентов.
*   `result_*.json` — структурированные данные (сентимент, триггеры, барьеры).

## Конфигурация

Основные настройки в `config.py`:
*   `CATEGORIES`: Список экспертов.
*   `COMMUNICATION_RULES`: Максимум раундов общения (`max_rounds`).
*   `YANDEX_GPT_CONFIG`: Лимиты токенов и кэширование.
