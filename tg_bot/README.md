# Telegram-бот для мультиагентной симуляции

Интерфейс для запуска пайплайна мультиагентной симуляции (`pipeline_agents`) через Telegram. Пользователь задаёт финансовый вопрос и целевые аудитории — бот парсит запрос, запускает генерацию синтетических персон и мультиагентное рассуждение, возвращает агрегированный результат с кнопками для детализации.

---

## Как работает

1. **Разбор запроса.** Сообщение пользователя проходит через YandexGPT (`llm.py::parse_query_with_llm`) — извлекаются целевые аудитории, соотношение между ними и финансовый вопрос в формате "да / нет".
2. **Подтверждение.** Бот показывает разобранные параметры и ждёт подтверждения через inline-кнопки (`keyboards.py`).
3. **Выбор количества персон.** Пользователь выбирает 5 / 10 / 15 / 20 персон.
4. **Выбор соотношения ЦА** (если их несколько и соотношение не задано явно в запросе).
5. **Запуск анализа.** `pipeline.py::run_full_analysis` → новостной контекст → генерация персон (PGM + k-NN OCEAN) → мультиагентное рассуждение. Прогресс этапов показывается в чате с live-progress bar.
6. **Результат.** Выводится сводка (% ДА / % НЕТ + средняя уверенность), дополнительные кнопки:
   - **Рассуждения** — примеры reasoning по одной "ДА" и одной "НЕТ"-персоне на каждую ЦА.
   - **Новостной фон** — список факторов и резюме новостного контекста.
   - **Скачать архив** — zip с полными результатами симуляции + топ-10 новостей по каждой теме в подпапке `news/`.
   - **Новый запрос** — сброс состояния.

## Структура

| Файл | Назначение |
|------|------------|
| `bot.py` | Точка входа. Инициализация aiogram, регистрация роутеров, запуск polling. |
| `handlers.py` | Обработчики сообщений и callback-кнопок. Вся FSM-логика диалога. |
| `keyboards.py` | Inline-клавиатуры (подтверждение, выбор персон, соотношение, результат). |
| `formatters.py` | Форматирование HTML-сообщений, построение zip-архива с результатами. |
| `llm.py` | Обращение к YandexGPT для парсинга запроса и вывода ЦА. |
| `pipeline.py` | Тонкая обёртка над `pipeline_agents.PipelineRunner`. |
| `config.py` | Токен бота, URL meta-agent, таймауты. |

## Запуск

### Требования

- Python 3.10+
- Работающий пайплайн `pipeline_agents` (см. корневой `README.md`)
- Telegram-токен бота (получить у `@BotFather`)
- Ключи YandexGPT (folder_id + IAM-токен)

### Переменные окружения / config

В `tg_bot/config.py`:
```python
BOT_TOKEN = "..."  
YANDEX_FOLDER_ID = "..."
YANDEX_IAM_TOKEN = "..."
META_AGENT_URL = "http://..."
ANALYSIS_TIMEOUT = 600   
```

### Старт

```bash
cd tg_bot
python bot.py
```

Бот начинает polling. Отправь `/start` в Telegram.

## Надёжность

- **Retry при сетевых сбоях Telegram.** Все отправки сообщений обёрнуты в `_tg_retry` с экспоненциальной задержкой (обработка `TelegramNetworkError`, `TelegramRetryAfter`).
- **Fallback устаревших callback-запросов.** Если кнопка нажата после истечения callback-токена (>15 сек), `callback.answer()` молча проглатывается — основная логика продолжает работу.
- **Таймаут анализа.** `asyncio.wait_for(ANALYSIS_TIMEOUT)` — если пайплайн завис, бот корректно сообщит об этом.
- **Прогресс симуляции.** Колбэк `simulation_progress_callback` из `SimulationManager` дроссируется (не чаще 1 апдейта в 2.5 сек) чтобы не превышать rate-limit Telegram.
